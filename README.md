# muebleria-rene

Cotizador para Mueblería René. Este repo guarda **solo la documentación**:
specs de diseño y planes de implementación en `docs/superpowers/`.

El código vive en dos repos aparte, que se clonan dentro de esta carpeta
(y están ignorados por git aquí):

| Carpeta     | Repo                                                        |
| ----------- | ----------------------------------------------------------- |
| `frontend/` | https://github.com/HiGonz/muebleria-rene-frontend — Next.js |
| `backend/`  | https://github.com/HiGonz/muebleria-rene-backend — Laravel  |

```bash
git clone https://github.com/HiGonz/muebleria-rene-frontend.git frontend
git clone https://github.com/HiGonz/muebleria-rene-backend.git backend
```

## Documentación

- `docs/superpowers/specs/` — specs de diseño, una por feature
- `docs/superpowers/plans/` — planes de implementación por tareas
